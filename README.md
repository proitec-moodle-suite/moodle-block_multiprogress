## 📖 Visão Geral

O **`block_multiprogress`** é um bloco personalizado do Moodle desenvolvido para a suíte ProITEC do IFRN. Ele permitia exibir uma barra de progresso consolidada para acompanhar o progresso dos estudantes em múltiplas trilhas de conhecimento do curso ProITEC (*Matemática*, *Língua Portuguesa*, *Ética e Cidadania*, *Seminário de Integração*).

- **Design de Referência Original**: [Adobe XD Design](https://xd.adobe.com/view/e0cfadb2-e6eb-42c7-b4b3-78202cf32443-b59c/) (também disponível em `assets/img/design.jpg`).

## 📥 Instalação (Legada)

1. Baixe ou clone o repositório dentro do diretório de blocos da sua instalação Moodle:
   ```bash
   cd /caminho/do/seu/moodle/blocks
   git clone git@github.com:proitec-moodle-suite/moodle-block_multiprogress.git multiprogress
   ```
2. Acesse a administração do Moodle (`/admin`) para efetuar a atualização do banco de dados.
